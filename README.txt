DEZURI LIMITED — WEBSITE PREVIEW (VERSION 3)

HOW TO VIEW
1. Extract the ZIP file.
2. Double-click open-preview.bat, or double-click index.html.
3. The website opens in your default browser.

WHAT'S INCLUDED
- Updated Dezuri Limited branding and attached logo
- Expanded company, service and project sections
- Residential, commercial, civil-works and consulting galleries
- Existing client and insight sections
- Contact details and an email-enquiry form

NOTE ON THE ENQUIRY FORM
The form opens an email draft to info@dezuri.com in the visitor's default email application.
It does not send data to a server.

FILES
index.html       Main page
styles.css       Styling
script.js        Navigation, gallery and email-form behaviour
assets/          Images and logos used by the page
